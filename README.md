# Dusk Client

Official Windows releases for the Dusk Minecraft launcher and its bundled client.

Download the latest installer from [Releases](https://github.com/Clenzzeyy/DuskClient/releases/latest).

Installed versions from 5.58.22 onward check for updates and download them in the background by default. Updates install when the launcher closes, once Minecraft is closed.

This repository hosts release files, not the launcher source code.

Dusk is an independent project and is not affiliated with Mojang or Microsoft.
